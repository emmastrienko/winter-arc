# Day 28: Intro DP & Timed Mock Interview Suite

> *"Dynamic programming is not magic; it is memoized recursion over overlapping subproblems with optimal substructure."*

---

## 1. Dynamic Programming Framework
1. **Define State**: `dp[i]` represents the optimal solution up to index $i$.
2. **Transition Formula**: How does `dp[i]` compute from previous states (`dp[i-1]`, `dp[i-2]`)?
3. **Base Cases**: `dp[0]`, `dp[1]`.
4. **Order of Computation**: Memoized top-down or tabulated bottom-up.
